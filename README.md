# 免费大模型平台导航 | Free LLM Platforms Hub

一个单文件静态网页，收录**国内外 14 个可免费接入的大模型 API 平台**、**15 项可领取的免费额度**、**22 张厂商卡册**与 **TOP 20 模型排行榜**，帮你判断「能不能接进代码」和「免费模型大概能干什么」。

## 查看方式

- **在线查看**：https://821920046.github.io/free-llm-platforms-hub/ （GitHub Pages）
- **本地查看**：双击打开 `index.html`，无需任何依赖或服务器

## 页面板块

1. **厂商卡册**：参考 AIHOT「我的卡册」视觉，把 22 个厂商做成紧凑小卡——顶部额度值、品牌色 logo、厂商名、稀有度菱形、右下 ×N 收录数；彩色渐变描边表示稀有度，灰度虚线表示「限产品内使用」。点卡片即筛选该厂商的全部条目，点左上角圆点可记录「已领」（保存在本机浏览器）。
2. **平台卡片**：14 家平台，标注免费方式、代表免费模型、OpenAI 兼容性、官网 / 文档链接。
3. **免费额度羊毛榜**：15 项额度，按每日 5 / 每月 4 / 限时 6 分类，每条标注额度、适用模型、限制条件、核实日期与领取链接；其中 11 项「可当 API 用」。
4. **模型排行榜 TOP 20**：引用 AIHOT 综合榜前 20 名，含厂商、上线日期、评测覆盖、输入 / 输出价、评分条与「和免费额度的关系」，支持国产 / 开源 / 免费相关筛选及表头排序。
5. **平台快速对比**：14 行表格，一屏看清各平台差异。

## 页面功能

- 全局搜索框：按平台名、厂商名、模型名、额度关键词实时过滤平台 / 额度 / 榜单，并显示三项结果计数
- 三组独立筛选：平台（全部 / 国内 / 国际）、额度（全部 / 每日 / 每月 / 限时 / 仅 API 可用）、榜单（全部 / 国产 / 开源 / 与免费额度相关）
- 排行榜点击「输入价 / 输出价 / AIHOT 评分」表头可切换升降序
- 卡册点击联动筛选与滚动定位，再次点击取消；「已领」状态用 localStorage 持久化
- 无匹配结果时给出空状态提示
- 纯 HTML + 内嵌 CSS/JS，无外部依赖，移动端自适应
